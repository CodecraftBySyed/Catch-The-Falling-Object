# Catch the Falling Objects

An engaging browser-based game where players control a basket to catch falling objects while avoiding bombs.

## Game Features

- Fast-paced gameplay with increasing difficulty
- Multiple object types with different point values
- Power-up system for basket size enhancement
- Level progression with increasing speed
- Lives system and timer-based gameplay
- High score tracking using local storage
- Responsive design for both desktop and mobile play
- Smooth animations and sound effects

## Object Types

- 🔴 Red objects: 1 point
- 🟢 Green objects: 3 points
- 🟡 Gold objects: 5 points
- 🟣 Purple objects: Power-ups (temporarily increases basket size)
- ⚫ Black objects: Bombs (avoid these!)

## Controls

- **Desktop**: Mouse movement or left/right arrow keys
- **Mobile**: Touch and drag to move the basket

## Game Mechanics

- Each level increases object falling speed and spawn rate
- Leveling up adds 10 seconds to your timer
- Missing regular objects reduces your lives
- Catching bombs reduces your lives
- Game ends when you run out of lives or time

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.0
- Bootstrap Icons
- Howler.js for sound effects

## Installation

No installation required! Simply open the HTML file in any modern web browser that supports HTML5.
